# Омск Гид

Многостраничный туристический сайт бота [@OmskGuide55_Bot](https://t.me/OmskGuide55_Bot).
Контакт администратора: [@baerovich](https://t.me/baerovich).

## Запуск

Нужен Python 3.10 или новее. Дополнительные библиотеки не нужны.

```powershell
python server.py
```

Откройте [http://127.0.0.1:8000](http://127.0.0.1:8000).
В Windows можно дважды щёлкнуть `start.bat`. Сервер работает, пока открыто его окно.
Простое открытие HTML оставляет доступ к оформлению и каталогу; для аккаунтов,
общих отзывов, дневника, погоды, афиши и управления запускайте сервер.

## Администратор

Создайте административную учётную запись локальной командой:

```powershell
python server.py --create-admin
```

Введите свой email и отдельный пароль длиной не менее 12 символов. Пароль вводится
скрыто и хранится только в виде scrypt-хеша. После этого войдите с этими данными
на [странице управления](http://127.0.0.1:8000/admin.html).

В Windows ту же настройку можно открыть двойным щелчком по `admin-setup.bat`.

Отображаемое имя административного аккаунта — `@baerovich`. Публичная регистрация
с таким именем не выдаёт прав администратора. Проверка прав выполняется на сервере.
Telegram-токен не нужен: сайт содержит ссылки на существующего бота, но не меняет его код.

## Страницы и функции

- `index.html`: презентация, быстрые прогулки, погода, галерея.
- `places.html`: 50 исходных мест, поиск, фильтры, карта, случайный выбор,
  избранное, отметки посещений, сравнение 2–4 мест, озвучивание и предложения мест.
- `routes.html`: пять маршрутов, конструктор по интересам, прогулки на 30/60/90 минут,
  подбор по настроению, замена уличных остановок на помещения, бюджет на группу,
  ссылка, QR-код, текстовый экспорт и печать.
- `guide.html`: аудиогид средствами браузера, сезоны, текущая погода,
  викторина, факты, сезонный чек-лист, крупный интерфейс.
- `journal.html`: сохранённые и посещённые места, достижения, личные заметки
  с фотографиями, экспорт дневника и статусы предложений.
- `reviews.html`: общие отзывы с оценками, фотографиями и аватарками;
  отправка только после входа, публикация после одобрения администратора.
- `events.html`: автоматически обновляемая официальная афиша Омского театра драмы
  и события, добавленные администратором. Фильтр дат, выбор часового пояса.
- `about.html`: возможности бота, инструкция, контакты и предоставленный QR-код.
- `admin.html`: редактор каталога RU/EN, фото, цены, координаты, экспорт JSON,
  модерация отзывов и предложений, создание и редактирование событий.

На всех страницах — русский/английский интерфейс, светлая/тёмная темы,
адаптивная вёрстка и крупные элементы. Названия импортированных спектаклей
сохраняются в оригинале, как у организатора. Голоса аудиогида зависят от устройства.

## Данные и внешние источники

- SQLite создаётся в `private/omsk.sqlite3`; каталог, пользователи, сессии,
  дневники, отзывы, предложения и события сохраняются между запусками.
- `private/` закрыта для HTTP-доступа и исключена из Git. Для резервной копии
  остановите сервер и сохраните всю эту папку. При публикации нужен постоянный диск.
- Исходные данные: `data/places.json`. Они загружаются в базу только при первом запуске.
  Дальше редактируйте каталог в админ-панели. JSON можно скачать оттуда.
- Гостевое избранное хранится в браузере. После регистрации оно переносится в профиль;
  при входе в существующий профиль загружаются данные этого профиля.
- Погода: [Open-Meteo](https://open-meteo.com/en/docs), запрос с фиксированными
  координатами Омска. Кеш 10 минут, сохранённые данные при сбое явно помечаются.
- Афиша: [официальный театр драмы](https://omskdrama.ru/affiche/), кеш на час.
  Если формат источника изменится, сайт покажет сохранённое расписание с предупреждением
  или ссылку на официальный источник. Проверяйте билеты у организатора.
- Рейтинги и бюджеты исходного каталога демонстрационные. Большинство фото —
  подписанные заглушки. Ссылки на реальные фото и лицензии находятся в подвале.
- Leaflet и генератор QR включены локально; фотографии, веб-шрифты,
  карта OpenStreetMap, погода и импорт афиши используют интернет.

## Размещение

Это локальный Python-сервер с SQLite, а не версия для статического хостинга.
Для публичного доступа разместите проект на сервере с постоянным диском и HTTPS,
используйте обратный прокси и включите `SECURE_COOKIES=1`. Запускайте процесс
непривилегированным пользователем под менеджером процессов. Не размещайте
`private/` в общедоступной папке веб-сервера.

```powershell
$env:SECURE_COOKIES = '1'
python server.py --host 127.0.0.1 --port 8000
```

Для проверки по локальной сети без HTTPS временно оставьте `SECURE_COOKIES`
неустановленной и запускайте `python server.py --host 0.0.0.0`.
QR маршрута работает на другом телефоне, если сам адрес сайта доступен с этого телефона.

## Проверки и изменение вёрстки

```powershell
python -m unittest discover -s tests -v
```

Тесты используют отдельную временную базу и не создают пользователей в основной.
HTML-страницы можно править напрямую. Для воспроизводимой генерации общей шапки,
разделов и форм используйте `tools/build_pages.py` и `templates/`:

```powershell
python tools/build_pages.py
```

Общие стили: `assets/styles.css` и `assets/pages.css`. Поведение:
`assets/app.js`, компоненты `assets/components.js`, двуязычные тексты `assets/content.js`.

Дополнительные проверки интерфейса: `node tests/test_frontend.cjs` (нужен `jsdom`;
путь к пакету можно передать через `JSDOM_PATH`).
